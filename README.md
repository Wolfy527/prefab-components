# Prefab Components

Unity authoring components for VRChat prefabs.

<a href="https://wolfy527.github.io/prefab-components/?install=1">
  <img src=".github/assets/add-to-vcc-button.svg" alt="Add Prefab Components to VCC" width="132">
</a>

VCC repository: `https://wolfy527.github.io/prefab-components/index.json`

## Install

Install `Wolfy_527 - Prefab Components` through VCC.

A standalone Unity package is also available on the
[Releases](https://github.com/Wolfy527/prefab-components/releases) page. It
keeps an installed VCC package, updates an older fallback, and does not
downgrade a newer fallback.

### Older Glizzy installs

VCC and the standalone installer preserve existing prefab references while
moving the old Scripts folder and Ghost Material out of `Assets`.

## Includes

- Live Mirroring authoring component and custom inspector
- Editor-only scene preview ghosts
- Upload-safe authoring cleanup
- Shared editor UI

## Requirements

- Unity 2022.3
- VRChat SDK - Avatars 3.7 or newer within 3.x
