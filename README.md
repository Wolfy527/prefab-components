# Prefab Components

Unity authoring components for VRChat prefabs.

[![Add Prefab Components to VCC](https://img.shields.io/badge/Add_to_VCC-Prefab_Components-ef8d45?style=for-the-badge)](https://wolfy527.github.io/prefab-components/?install=1)

VCC repository: `https://wolfy527.github.io/prefab-components/index.json`

## Install

Install `Wolfy_527 - Prefab Components` through VCC.

A standalone Unity package is also available on the
[Releases](https://github.com/Wolfy527/prefab-components/releases) page. Use one
installation method per project.

### Older Glizzy installs

VCC removes the old Scripts folder and Ghost Material automatically.

Before using the standalone package, close Unity and remove
`Assets/Wolfy_527/~ Supporting Files/Scripts` and the old Ghost Material from
`Assets`.

## Includes

- Live Mirroring authoring component and custom inspector
- Editor-only scene preview ghosts
- Upload-safe authoring cleanup
- Shared editor UI

## Requirements

- Unity 2022.3
- VRChat SDK - Avatars 3.7 or newer within 3.x
